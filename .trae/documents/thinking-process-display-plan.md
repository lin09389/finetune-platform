# 思考过程显示功能实现计划

## 目标

配置系统以区分显示最终输出和思考过程：
- **思考过程默认隐藏** ✅
- **用户可通过按钮切换显示/隐藏** ✅
- 思考过程使用较小字体（12px）✅
- 最终输出使用正常字体（15px）✅

## 实现状态

### ✅ 阶段一：前端组件开发（已完成）

#### ✅ 步骤 1.1：创建 ThinkingProcess 组件
- 文件：`client/src/components/ThinkingProcess.tsx`
- **核心功能**：
  - 按钮切换显示/隐藏（点击展开/收起）
  - 默认隐藏（`defaultExpanded = false`）
  - 小字体样式（12px）
  - 灰色背景区分
  - Framer Motion 动画效果

**组件特性**：
```tsx
interface ThinkingProcessProps {
  content: string;
  defaultExpanded?: boolean;  // 默认 false，隐藏状态
  isStreaming?: boolean;      // 流式输出时显示指示器
}
```

#### ✅ 步骤 1.2：修改 ChatMessage 组件
- 文件：`client/src/components/ChatMessage.tsx`
- 添加 `thinkingContent` prop
- 集成 ThinkingProcess 组件

## UI 设计

### 消息结构
```
┌─────────────────────────────────────────┐
│ [思考过程 ▼]  ← 点击按钮展开/收起          │
├─────────────────────────────────────────┤
│ ┌─────────────────────────────────────┐ │
│ │ 思考过程内容（默认隐藏）              │ │
│ │ 字体: 12px, 颜色: #666              │ │
│ │ 背景: #fafafa                       │ │
│ └─────────────────────────────────────┘ │
├─────────────────────────────────────────┤
│ 最终输出内容                             │
│ 字体: 15px, 颜色: #333                   │
└─────────────────────────────────────────┘
```

### 按钮状态
- **收起状态**：`[思考过程 ▼]` + 箭头向下
- **展开状态**：`[收起思考过程 ▲]` + 箭头向上

### 阶段二：后端 API 增强（待实现）

如需从后端获取真实思考过程数据，需要：

1. 修改 `server/api/inference.py`
2. 流式响应添加 `thinking` 类型消息
3. 前端解析并分离思考过程和最终输出

**响应格式示例**：
```json
{
  "type": "thinking",
  "content": "让我分析一下这个问题..."
}
{
  "type": "output",
  "content": "这是最终答案..."
}
```
