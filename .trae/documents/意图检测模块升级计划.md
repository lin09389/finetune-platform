# 意图检测模块全面升级计划

## 一、现状分析

### 当前实现
- **文件**: `server/agent/intent.py`
- **方法**: 基于正则表达式的规则匹配
- **置信度**: 固定值 0.9
- **模式数量**: 约25个规则

### 存在的问题

| 问题 | 描述 |
|------|------|
| 置信度评估缺失 | 固定置信度，无法区分匹配质量 |
| 语义理解不足 | 仅支持关键词匹配，无法理解复杂语义 |
| 上下文缺失 | 无法结合对话历史理解意图 |
| 相似意图混淆 | 无法区分相似操作（如"打开文件"vs"打开应用"） |
| 模式覆盖有限 | 约25个规则，覆盖场景不足 |
| 无性能评估 | 缺少准确率、召回率、F1等指标 |

---

## 二、升级目标

### 2.1 核心目标

| 指标 | 当前 | 目标 |
|------|------|------|
| 意图识别准确率 | ~70% | ≥95% |
| 相似意图区分度 | 低 | 高 |
| 置信度评估 | 无 | 动态评估 |
| 上下文理解 | 无 | 支持 |
| 模式覆盖 | 25个 | 100+ |

### 2.2 功能目标

1. **多级置信度评估**: 高/中/低置信度分类
2. **上下文感知**: 结合对话历史理解意图
3. **语义相似度**: 支持模糊匹配和语义理解
4. **低置信度处理**: 自动请求用户确认
5. **性能监控**: 实时统计准确率、召回率、F1

---
