## 二、修复方案

### 2.1 P0-1: 双重锁设计修复

**问题**：`TrainingState` 类同时定义了 `asyncio.Lock` 和 `threading.Lock`，但 `asyncio.Lock` 从未使用。

**修复方案**：
1. 移除未使用的 `asyncio.Lock`
2. 统一使用 `threading.Lock` 进行线程同步
3. 将所有 `async` 方法改为同步方法（因为实际都在工作线程中执行）

**修改文件**：`server/core/training_state.py`

### 2.2 P0-2: 任务取消功能完善

**问题**：`PriorityQueue` 不支持随机删除，导致队列中的任务无法取消。

**修复方案**：
1. 使用 `dict` 跟踪所有任务（包括队列中的）
2. 标记取消的任务，在工作线程中跳过执行
3. 添加 `cancel_pending_task` 方法

**修改文件**：`server/core/training_queue.py`

### 2.3 P0-3: WebSocket 连接泄漏修复

**问题**：`broadcast` 方法中异常处理后的 `disconnect` 调用可能失败。

**修复方案**：
1. 添加连接超时机制
2. 使用 `try-finally` 确保清理
3. 添加心跳检测

**修改文件**：`server/api/training.py`

### 2.4 P0-4: 全局状态管理重构

**问题**：多个全局变量延迟初始化，无统一管理机制。

**修复方案**：
1. 创建 `TrainingContext` 类统一管理所有状态
2. 使用 FastAPI 依赖注入管理生命周期
3. 添加应用启动/关闭时的初始化/清理钩子

**修改文件**：`server/api/training.py`, `server/main.py`

### 2.5 P0-5: 测试覆盖率提升

**问题**：测试覆盖率严重不足。

**修复方案**：
1. 添加 `TrainingState` 单元测试
2. 添加 `TrainingQueue` 单元测试
3. 添加训练流程集成测试
4. 使用 Mock 隔离外部依赖

**修改文件**：`server/tests/test_training.py`, 新增测试文件
