# Checklist

## Phase 1: CUA 核心模块

- [ ] CUA 模块基础结构已创建（`server/cua/__init__.py` 等）
- [ ] 屏幕捕获模块可正常工作，支持多显示器
- [ ] 鼠标操作模块可正常工作，支持点击、移动、拖拽、滚动
- [ ] 键盘操作模块可正常工作，支持文本输入和快捷键
- [ ] 窗口管理模块可正常工作，支持窗口列表和状态操作

## Phase 2: OCR 与视觉识别

- [ ] OCR 识别模块可正常工作，支持中英文识别
- [ ] 视觉识别模块可正常工作，支持模板匹配
- [ ] 文本定位功能可正常工作

## Phase 3: 操作录制与回放

- [ ] 操作录制模块可正常录制鼠标键盘事件
- [ ] 操作回放模块可正常回放录制的操作序列
- [ ] 回放速度控制功能正常

## Phase 4: 安全控制

- [ ] 操作权限分级已实现（只读、受限、完全）
- [ ] 敏感操作检测和确认机制正常工作
- [ ] 操作审计日志完整记录

## Phase 5: CUA Skills

- [ ] `ScreenshotSkill` 可正常截取屏幕
- [ ] `MouseClickSkill` 可正常点击指定位置
- [ ] `KeyboardTypeSkill` 可正常输入文本
- [ ] `WindowListSkill` 可正常列出窗口
- [ ] `ClickTextSkill` 可正常点击包含特定文本的元素
- [ ] `RecordActionsSkill` 和 `PlaybackActionsSkill` 可正常工作

## Phase 6: 记忆-技能联动

- [ ] 记忆感知技能基类可正常注入记忆上下文
- [ ] 操作结果可自动存储到记忆系统
- [ ] 用户偏好学习功能正常工作
- [ ] 技能参数优化功能正常

## Phase 7: MCP 协议

- [ ] MCP 客户端可正常连接外部服务器
- [ ] MCP 工具可动态发现和注册
- [ ] MCP 工具可正常调用
- [ ] MCP 服务器可转换为 Skills

## Phase 8: API 端点

- [ ] `POST /cua/screenshot` 端点正常工作
- [ ] `POST /cua/mouse/click` 端点正常工作
- [ ] `POST /cua/keyboard/type` 端点正常工作
- [ ] `POST /cua/window/list` 端点正常工作
- [ ] `POST /cua/record/*` 端点正常工作
- [ ] `GET /mcp/tools` 端点正常工作

## Phase 9: 前端界面

- [ ] CUA 控制面板页面正常显示
- [ ] 实时屏幕预览组件正常工作
- [ ] 操作录制界面正常工作
