# Frontend Design & UI-UX-PRO-MAX

## Core Principles

- Avoid generic AI-looking blue-purple gradients, excessive glassmorphism, and decorative card-heavy layouts.
- Build production-grade interfaces with clear hierarchy, purposeful color, refined spacing, and concrete interaction states.
- Match the interface to the domain: operational tools should be dense, quiet, and scannable; expressive apps can carry more visual character.
- Prefer functional polish over decoration: hover, focus, active, loading, empty, error, and responsive states should all feel intentional.

## Workflow

1. Inspect the existing UI conventions, components, tokens, and libraries before designing.
2. Choose a visual direction that fits the product and audience.
3. Implement complete controls and states, not only a static layout.
4. Verify text fit, responsive behavior, and visual balance across desktop and mobile.
5. Remove decorative elements that do not support comprehension or action.

## Implementation Guidance

- Use established project components and icon libraries when available.
- Keep cards for repeated items, modals, or framed tools; avoid cards nested inside cards.
- Use stable dimensions for toolbars, grids, boards, counters, and fixed-format widgets.
- Keep border radii restrained unless the existing design system differs.
- Do not rely on viewport-scaled font sizes or negative letter spacing.

## Checklist

- Text hierarchy is clear and readable.
- Primary and secondary actions are visually distinct.
- Interactive elements have hover, focus, active, and disabled states.
- Mobile tap targets are usable.
- The palette is not dominated by one hue family.
- Text does not overlap or overflow its container.
