 架构计划：OpenClaw 风格 Agent 对话体验                                                                                                                                          │
│                                                                                                                                                                                 │
│ 架构概览（最终状态）                                                                                                                                                            │
│                                                                                                                                                                                 │
│ 用户输入                                                                                                                                                                        │
│     ↓                                                                                                                                                                           │
│ 意图预览 (debounce 500ms, /agent/detect-intent)                                                                                                                                 │
│     ↓                                                                                                                                                                           │
│ 意图气泡显示 (高置信度自动执行，否则等待确认)                                                                                                                                   │
│     ↓                                                                                                                                                                           │
│ /agent/unified-execute (SSE 流)                                                                                                                                                 │
│     ├─ 工具意图 → UnifiedExecutor (SSE 推送 step_start/step_complete)                                                                                                           │
│     │     ├─ agent/operations/file/  (文件操作)                                                                                                                                 │
│     │     ├─ agent/operations/cua/   (CUA 操作)                                                                                                                                 │
│     │     └─ server/skills/          (Skills 系统，注入到 _action_handlers)                                                                                                     │
│     └─ 对话意图 → 流式 LLM 生成 (delta 事件)                                                                                                                                    │
│     ↓                                                                                                                                                                           │
│ 执行 Timeline 实时展示 → 自然衔接对话                                                                                                                                           │
│                                                                                                                                                                                 │
│ Context                                                                                                                                                                         │
│                                                                                                                                                                                 │
│ 当前项目已有相当完善的 Agent 执行系统（server/agent/），但前端 Chat 页面与 Agent 执行之间存在严重的架构断层：                                                                   │
│                                                                                                                                                                                 │
│ - 前端 Chat 页面 (client/src/pages/Chat/index.tsx) 是 Playground 体验，需要用户手动切换 Agent Mode 开关才能触发 Agent 执行                                                      │
│ - 意图检测在 server/agent/intent/ 已高度完善（多方法融合、置信度阈值、策略路由），但前端完全没有使用这个检测结果来自动路由                                                      │
│ - 后端 /agent/chat-execute 接口是单次检测-执行，缺乏自动多步循环和实时 SSE 进度推送                                                                                             │
│ - Gateway 系统（server/gateway/）已实现 WebSocket 会话管理，但未与前端 Agent 体验集成                                                                                           │
│                                                                                                                                                                                 │
│ 这导致用户体验碎片化：用户不知道何时该开启 Agent Mode，Agent 能力被锁在 Playground 之外。                                                                                       │
│                                                                                                                                                                                 │
│ 用户决策                                                                                                                                                                        │
│                                                                                                                                                                                 │
│ - 后端: 两者融合 — server/agent/ 负责意图检测和策略路由，server/skills/ 负责实际执行，合并为一个统一执行层                                                                      │
│ - Playground: 完全融合 — 移除 Agent Mode Toggle 和 Playground 分离，统一为单一对话界面                                                                                          │
│ - 实施范围: 全部 5 个 Phase                                                                                                                                                     │
│                                                                                                                                                                                 │
│ 构建一个统一对话界面，实现像 OpenClaw 一样的体验：                                                                                                                              │
│ 用户自然输入目标 → 系统自动检测意图 → 自动路由到正确模式 → 实时展示执行过程 → 自然衔接对话                                                                                      │
│                                                                                                                                                                                 │
│ 实施方案                                                                                                                                                                        │
│                                                                                                                                                                                 │
│ Phase 1: 统一入口层 — /agent/unified-execute SSE 流式接口                                                                                                                       │
│                                                                                                                                                                                 │
│ 融合架构:                                                                                                                                                                       │
│                                                                                                                                                                                 │
│ 意图检测层 (server/agent/intent/)                                                                                                                                               │
│     ↓                                                                                                                                                                           │
│ 策略路由层 (server/agent/intent/policy.py) → choose_route_with_thresholds                                                                                                       │
│     ↓                                                                                                                                                                           │
│ 执行路由                                                                                                                                                                        │
│   ├─ Tool Action → UnifiedExecutor (server/agent/core/executor.py)                                                                                                              │
│   │                  ├─ 注册 FileOperationHandler (来自 agent/operations/file/)                                                                                                 │
│   │                  ├─ 注册 CUAOperationHandler (来自 agent/operations/cua/)                                                                                                   │
│   │                  └─ 注册 Skills Handler (来自 server/skills/) → 注入到 _action_handlers                                                                                     │
│   └─ LLM Generation → Ollama / HuggingFace 流式推理                                                                                                                             │
│                                                                                                                                                                                 │
│ 融合策略:                                                                                                                                                                       │
│ - server/agent/core/executor.py 的 UnifiedExecutor 是唯一执行入口                                                                                                               │
│ - server/skills/ 通过 register_action_handler() 注入到 UnifiedExecutor                                                                                                          │
│ - 不再有 server/skills/registry.py 独立注册，统一使用 agent 的 ActionType                                                                                                       │
│                                                                                                                                                                                 │
│ 新建文件: server/api/agent_unified.py                                                                                                                                           │
│                                                                                                                                                                                 │
│ 现有的 /agent/chat-execute 是同步请求，无法流式推送执行进度。创建统一的 SSE 接口：                                                                                              │
│                                                                                                                                                                                 │
│ @router.post("/unified-execute")                                                                                                                                                │
│ async def unified_execute(request: UnifiedExecuteRequest):                                                                                                                      │
│     """统一的对话入口：                                                                                                                                                         │
│     1. 即时意图检测（<50ms）                                                                                                                                                    │
│     2. 如果是工具意图 → 启动 Agent Loop，SSE 流式推送每步状态                                                                                                                   │
│     3. 如果是对话意图 → 直接流式生成回复                                                                                                                                        │
│     4. 如果是混合 → 先执行工具步骤，再衔接模型推理                                                                                                                              │
│     """                                                                                                                                                                         │
│                                                                                                                                                                                 │
│ 事件流类型:                                                                                                                                                                     │
│ - intent_detected: 意图已识别（action, confidence, routing_decision）                                                                                                           │
│ - step_start: 步骤开始（step_index, action, params）                                                                                                                            │
│ - step_progress: 步骤进度（action, progress%）                                                                                                                                  │
│ - step_complete: 步骤完成（action, result_summary）                                                                                                                             │
│ - step_error: 步骤失败（action, error, recovery_hint）                                                                                                                          │
│ - tool_result: 工具结果（action, formatted_result）                                                                                                                             │
│ - generation_start: 切换到模型生成                                                                                                                                              │
│ - delta: 流式文本片段                                                                                                                                                           │
│ - done: 完成                                                                                                                                                                    │
│                                                                                                                                                                                 │
│ 路由决策逻辑（复用 policy.py 的阈值系统）:                                                                                                                                      │
│ - confidence >= 0.75 且 action 已知 → 直接执行                                                                                                                                  │
│ - confidence 0.45-0.75 → 展示预览，等待用户确认                                                                                                                                 │
│ - confidence < 0.45 或无 action → 对话模式                                                                                                                                      │
│                                                                                                                                                                                 │

│                                                                                                                                                                                 │

│ Agent Loop 执行过程中，需要将每步状态通过 SSE 推送到前端：                                                                                                                      │
│                                                                                                                                                                                 │
│ class SSELoopRunner:                                                                                                                                                            │
│     async def run_with_sse(                                                                                                                                                     │
│         self,                                                                                                                                                                   │
│         message: str,                                                                                                                                                           │
│         session_id: str,                                                                                                                                                        │
│         sse_queue: asyncio.Queue,  # 推送事件到这里                                                                                                                             │
│         max_steps: int = 5,                                                                                                                                                     │
│     ):                                                                                                                                                                          │
│         for step in range(max_steps):                                                                                                                                           │
│             await sse_queue.put(SSEEvent("step_start", {...}))                                                                                                                  │
│             result = await executor.execute(action, params)                                                                                                                     │
│             await sse_queue.put(SSEEvent("step_complete", {...}))                                                                                                               │
│                                                                                                                                                                                 │
│             if result.need_confirm:                                                                                                                                             │
│                 await sse_queue.put(SSEEvent("confirm_required", {...}))                                                                                                        │
│                 # 等待前端确认信号                                                                                                                                              │
│                 await wait_for_confirmation()                                                                                                                                   │
│                                                                                                                                                                                 │
│             if result.need_inference:                                                                                                                                           │
│                 await sse_queue.put(SSEEvent("generation_start", {...}))                                                                                                        │
│                 # 启动流式生成                                                                                                                                                  │
│                 async for chunk in generate_stream(message):                                                                                                                    │
│                     await sse_queue.put(SSEEvent("delta", {"content": chunk}))                                                                                                  │
│                 break                                                                                                                                                           │
│                                                                                                                                                                                 │
