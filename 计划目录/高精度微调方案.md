## 🏆 高精度微调方案

### 方案一：全参数微调 (Full Fine-tuning) ⭐⭐⭐⭐⭐

**精度保持**: 98-100%

**适用场景**:
- ✅ 有充足 GPU 资源 (24GB+ 显存)
- ✅ 对精度要求极高
- ✅ 数据集较大 (>1000 条)

**配置建议**:
```python
{
    "method": "full",           # 全参数微调
    "learning_rate": 1e-5,      # 较小学习率
    "epochs": 3,
    "batch_size": 4,
    "gradient_accumulation": 4,
    "max_seq_length": 1024,
    "warmup_ratio": 0.1,
    "weight_decay": 0.01,
    "lr_scheduler": "cosine",   # 余弦退火
}
```

**SWIFT 命令**:
```bash
swift sft \
  --stage sft \
  --learning_rate 1e-5 \
  --num_train_epochs 3 \
  --per_device_train_batch_size 4 \
  --gradient_accumulation_steps 4 \
  --max_length 1024 \
  --lr_scheduler_type cosine \
  --warmup_ratio 0.1
```

---

### 方案二：DoRA 微调 (Weight-Decomposed LoRA) ⭐⭐⭐⭐⭐

**精度保持**: 95-98%  
**显存占用**: 12GB (7B 模型)

**核心优势**:
- ✅ 分解权重为幅度和方向，更精细控制
- ✅ 接近全参数微调的精度
- ✅ 显存占用仅为 LoRA 水平

**配置建议**:
```python
{
    "method": "dora",           # DoRA 微调
    "lora_rank": 64,            # 较高秩
    "lora_alpha": 128,          # alpha = 2 * rank
    "lora_dropout": 0.05,
    "learning_rate": 2e-5,
    "epochs": 3,
    "batch_size": 2,
    "gradient_accumulation": 8,
}
```

**SWIFT 命令**:
```bash
swift sft \
  --stage sft-lora \
  --use_dora true \
  --lora_rank 64 \
  --lora_alpha 128 \
  --lora_dropout_p 0.05 \
  --learning_rate 2e-5
```

---

### 方案三：高秩 LoRA 微调 ⭐⭐⭐⭐

**精度保持**: 90-95%  
**显存占用**: 10GB (7B 模型)

**配置建议**:
```python
{
    "method": "lora",
    "lora_rank": 32,            # 高秩
    "lora_alpha": 64,
    "lora_dropout": 0.05,
    "learning_rate": 3e-5,
    "epochs": 3,
    "batch_size": 2,
    "gradient_accumulation": 8,
    "target_modules": "all",    # 微调所有线性层
}
```

**SWIFT 命令**:
```bash
swift sft \
  --stage sft-lora \
  --lora_rank 32 \
  --lora_alpha 64 \
  --lora_target_modules all \
  --learning_rate 3e-5
```

## 🔑 关键精度优化技术

### 1. 学习率调度策略

**推荐**: 余弦退火 (Cosine Annealing)

```python
{
    "lr_scheduler_type": "cosine",
    "warmup_ratio": 0.1,        # 10% 步数预热
    "learning_rate": 2e-5,
    "min_lr_ratio": 0.1,        # 最小学习率为初始的 10%
}
```

**效果**:
- ✅ 避免早期过拟合
- ✅ 后期精细收敛
- ✅ 提升 2-3% 精度

---

### 2. 混合精度训练 (AMP)

**推荐**: BF16 (优于 FP16)

```python
{
    "bf16": True,               # 使用 BF16
    "fp16": False,
    "optim": "adamw_torch",     # 稳定优化器
}
```

**优势**:
- ✅ BF16 数值范围更大，不易溢出
- ✅ 精度损失极小
- ✅ 显存占用减半

---

### 3. 梯度检查点 (Gradient Checkpointing)

```python
{
    "gradient_checkpointing": True,
}
```

**效果**:
- ✅ 显存占用减少 40%
- ✅ 支持更大 batch size
- ✅ 训练速度略微降低 (10-20%)

---

### 4. 早停策略 (Early Stopping)

```python
{
    "evaluation_strategy": "steps",
    "eval_steps": 100,
    "load_best_model_at_end": True,
    "metric_for_best_model": "eval_loss",
    "save_total_limit": 3,
}
```

**效果**:
- ✅ 自动选择最佳检查点
- ✅ 避免过拟合
- ✅ 提升泛化能力

---

### 5. 数据增强

**方法**:
```python
# 1. 回译增强
original → 翻译为英文 → 翻译回中文 → 新样本

# 2. 同义词替换
"很好" → "优秀"、"出色"、"极佳"

# 3. 句式重组
主动句 ↔ 被动句
```

**效果**:
- ✅ 数据集扩大 2-3 倍
- ✅ 提升 3-5% 泛化能力
- ✅ 减少过拟合

---

### 6. 标签平滑 (Label Smoothing)

```python
{
    "label_smoothing_factor": 0.1,
}
```

**效果**:
- ✅ 减少模型过度自信
- ✅ 提升泛化能力
- ✅ 特别适用于分类任务

---

### 7. 权重衰减 (Weight Decay)

```python
{
    "weight_decay": 0.01,       # 默认值
    # 或 0.001 (更保守)
}
```

**效果**:
- ✅ L2 正则化
- ✅ 减少过拟合
- ✅ 提升泛化

## 🎯 数据集质量优化

### 1. 数据清洗

```python
# 移除低质量样本
- 长度过短 (<10 字)
- 长度过长 (>2000 字)
- 包含乱码/特殊字符
- 重复样本
```

### 2. 数据平衡

```python
# 确保各类别样本数量均衡
- 对话类：30%
- 知识类：30%
- 推理类：20%
- 创作类：20%
```

### 3. 高质量样本优先

```python
# 人工标注质量评分
- 5 星：专家编写/审核
- 4 星：高质量用户贡献
- 3 星：普通用户贡献 (需审核)

# 训练时加权采样
高质量样本采样权重 = 2.0
普通样本采样权重 = 1.0
```

## 📊 精度评估指标

### 训练监控

| 指标 | 目标值 | 说明 |
|------|--------|------|
| Train Loss | 持续下降 | 应平滑下降，无大幅波动 |
| Eval Loss | 持续下降 | 与 Train Loss 差距<20% |
| Eval Accuracy | >85% | 根据任务而定 |
| Gradient Norm | <1.0 | 避免梯度爆炸 |

### 过拟合检测

```
过拟合信号:
- Train Loss 持续下降，Eval Loss 上升
- Train Accuracy > Eval Accuracy + 20%
- Gradient Norm 异常增大

解决方案:
- 早停
- 增加 Dropout
- 减少训练轮数
- 增加数据量
```
