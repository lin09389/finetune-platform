```python
def _apply_memory_preset(config: TrainingConfigInput):
    """应用显存预设配置"""
    
    if cfg.memory_preset == "6gb":
        # 6GB 显存：极致优化
        cfg.gradient_checkpointing = True
        cfg.gradient_accumulation = 16
        cfg.batch_size = 1
        cfg.quantization = 4
        cfg.bf16 = True
        cfg.use_flash_attn = True
        
    elif cfg.memory_preset == "8gb":
        # 8GB 显存：平衡优化
        cfg.gradient_checkpointing = True
        cfg.gradient_accumulation = 8
        cfg.batch_size = 2
        cfg.quantization = 8
        cfg.bf16 = True
        cfg.use_flash_attn = True
        
    elif cfg.memory_preset == "12gb":
        # 12GB 显存：DeepSpeed ZeRO-2
        cfg.gradient_checkpointing = True
        cfg.gradient_accumulation = 4
        cfg.batch_size = 2
        cfg.quantization = 0
        cfg.deepspeed_stage = 2
        cfg.offload_optimizer = True
```

## 🎯 使用指南

### 1. 选择显存预设

在训练页面选择显存优化预设：

- **🤖 自动检测**: 根据 GPU 显存自动选择
- **💾 6GB 显存**: 极致压缩，适合 RTX 3060 6GB
- **💾 8GB 显存**: 平衡优化，适合 RTX 3070 8GB
- **💾 12GB 显存**: DeepSpeed ZeRO-2，适合 RTX 3060 12GB

### 2. 手动调整 (可选)

- **梯度累积**: 越大越省显存，但训练越慢
- **量化位数**: 4bit 最省显存，8bit 精度更高
- **Flash Attention**: 开启后显存减少 20-30%，速度提升 10%

### 3. 启动训练

配置完成后点击"开始训练"，系统自动应用显存优化配置。
