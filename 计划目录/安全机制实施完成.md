## 🔧 技术实现

### 1. API Key 加密存储

**加密流程**:
```python
# 1. 生成 Fernet 密钥
key = Fernet.generate_key()

# 2. 加密 API Key
cipher = Fernet(key)
encrypted = cipher.encrypt(api_key.encode())

# 3. Base64 编码存储
ciphertext = base64.urlsafe_b64encode(encrypted).decode()

# 4. 保存到.vault 文件
vault[f"api_key:{key_id}"] = ciphertext
```

**解密流程**:
```python
# 1. 读取密钥
key = open('.encryption_key', 'rb').read()

# 2. 读取密文
ciphertext = vault[f"api_key:{key_id}"]

# 3. 解密
cipher = Fernet(key)
decrypted = cipher.decrypt(base64.urlsafe_b64decode(ciphertext))

# 4. 返回明文
return decrypted.decode()
```

### 2. 文件沙箱

**安全检查流程**:
```python
def safe_path(self, file_path: str, operation: str) -> Path:
    # 1. 转换为绝对路径
    path = (self.working_dir / file_path).resolve()
    
    # 2. 检查是否在工作目录内
    try:
        path.relative_to(self.working_dir)
    except ValueError:
        raise PermissionError("禁止访问工作目录外文件")
    
    # 3. 检查禁止模式
    for pattern in FORBIDDEN_PATTERNS:
        if re.search(pattern, str(path)):
            raise PermissionError("禁止访问的路径")
    
    # 4. 检查危险扩展名
    if operation == 'create':
        if path.suffix in DANGEROUS_EXTENSIONS:
            raise PermissionError("禁止创建危险文件")
    
    return path
```

### 3. 审计日志

**日志格式**:
```json
{
  "timestamp": "2026-03-08T16:00:00.000000",
  "action": "api_key_created",
  "user_id": "system",
  "resource": "key_abc123",
  "details": {"provider": "minimax"},
  "success": true
}
```

**日志类型**:
- `api_key_access` - API Key 使用
- `api_key_created` - API Key 创建
- `api_key_deleted` - API Key 删除
- `file_read/write/create/delete` - 文件操作
- `cloud_chat_access` - 云端聊天
- `security_event` - 安全事件

## 🚀 使用指南

### 第 1 步：保存 API Key（加密）

**前端调用**:
```typescript
// 保存到后端加密存储
const response = await fetch('http://127.0.0.1:8000/cloud/api-keys', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    provider: 'minimax-coding',
    api_key: '123456:abcdefghijklmnop'  // 明文传输（HTTPS 保护）
  })
})

const data = await response.json()
console.log('Key ID:', data.key_id)  // 保存 key_id
```

**后端处理**:
```python
# 生成 Key ID
key_id = f"key_{uuid.uuid4().hex[:12]}"

# 加密存储
secure_storage.store_api_key(key_id, provider, api_key)

# 返回 Key ID（不返回明文）
return {"key_id": key_id, "provider": provider}
```

---

### 第 2 步：使用加密的 API Key

**前端调用**:
```typescript
// 使用 key_id 调用云端 AI
const response = await fetch('http://127.0.0.1:8000/cloud/chat/stream', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    provider: 'minimax-coding',
    key_id: 'key_abc123',  // 使用 key_id，不传明文 key
    messages: [...]
  })
})
```

**后端处理**:
```python
# 从加密存储获取 API Key
api_key = secure_storage.get_api_key(key_id)

# 调用 AI 服务
provider = await get_provider(request.provider)
content = await provider.chat(
    messages=request.messages,
    model=request.model,
    api_key=api_key  # 使用解密的 Key
)

# 记录审计日志
audit_logger.log_cloud_chat_access(provider, request.model)
```
