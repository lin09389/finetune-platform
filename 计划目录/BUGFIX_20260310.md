## 问题 1: pytest.ini 配置语法错误 ✅ 已修复

### 问题描述
运行 `pytest` 时报错：
```

```

### 原因
配置文件使用了 TOML 格式 `[tool.pytest.ini_options]`，但内容却是 INI 格式语法，导致解析失败。

### 修复内容

**文件**: `server/pytest.ini`

```ini

python_files = ["test_*.py"]
addopts = [
    "-v",
    "--cov=server",
]

# 修复后 (标准 INI 格式)
[pytest]
testpaths = tests
python_files = test_*.py
python_classes = Test*
python_functions = test_*
asyncio_mode = auto
addopts = -v --strict-markers --tb=short
```

### 修复内容

#### 1. auth_middleware.py
```python

    return None

except Exception as e:
    logger.debug(f"Token 验证失败：{e}")
    return None
```

#### 2. file_sandbox.py
```python
# 修复前

    return False

# 修复后
except Exception as e:
    logger.debug(f"检查文件存在失败：{e}")
    return False
```

#### 3. gateway.py
```python
# 修复前
except:
    continue

# 修复后
except (json.JSONDecodeError, KeyError) as e:
    logger.debug(f"解析响应失败：{e}")
    continue
```

#### 4. test_deep_integration.py (并发测试)
```python
# 修复前
except:
    pass

# 修复后
except Exception:
    pass  # 忽略异常，测试并发场景下部分请求可能失败
```

### 修复原则
1. **生产代码**: 使用 `except Exception as e:` + 日志记录
2. **测试代码**: 使用 `except Exception:` + 注释说明忽略原因
3. **特定异常**: 能指定具体异常类型时优先指定（如 `json.JSONDecodeError`）
