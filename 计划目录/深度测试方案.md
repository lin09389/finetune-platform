## 1️⃣ 端到端场景测试

### 1.1 完整微调流程

```
用户故事：数据科学家小王要微调一个代码生成模型

步骤:
1. 上传数据集 (100MB JSONL)
2. 预览数据集 (分页、统计)
3. 选择基座模型 (CodeLlama-7b)
4. 配置训练参数 (LoRA, epochs=3, batch_size=8)
5. 启动训练任务
6. 监控训练进度 (实时 loss 曲线)
7. 训练完成，保存检查点
8. 加载微调模型进行推理
9. 验证推理结果
10. 导出模型

验证点:
- 每个步骤状态正确
- 数据不丢失
- 检查点完整可恢复
- 推理结果合理
```

### 1.2 RAG 完整流程

```
用户故事：开发者小李要构建项目知识库

步骤:
1. 上传项目文档 (PDF/MD/TXT)
2. 文档解析和分块
3. 向量化嵌入
4. 存储到向量数据库
5. 用户提问
6. 检索相关文档
7. 生成回答
8. 验证引用准确性

验证点:
- 文档解析正确
- 分块合理 (不截断语义)
- 检索相关性高
- 回答准确有引用
```

### 1.3 Agent 操作流程

```
用户故事：用户小张要让 AI 助手创建项目

步骤:
1. 用户请求："创建一个 Python 项目"
2. Agent 解析意图
3. 安全检查 (白名单、路径)
4. 执行文件创建
5. 写入初始化代码
6. 返回操作结果
7. 用户确认操作

验证点:
- 意图识别准确
- 安全检查生效
- 文件操作正确
- 审计日志记录
```

### 1.4 云端 AI 流程

```
用户故事：用户小赵要使用云端 AI 编程

步骤:
1. 配置 API Key (Minimax)
2. 加密存储
3. 切换到云端模式
4. 发送编程问题
5. 流式接收回答
6. 验证回答质量
7. 查看使用记录

验证点:
- API Key 加密
- 流式输出流畅
- 计费准确
- 审计日志完整
```
