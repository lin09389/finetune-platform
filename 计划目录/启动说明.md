# Finetune Platform 启动说明

## 快速启动

### Windows 用户

**方法 1：双击启动**
```
双击 start.bat
```

**方法 2：PowerShell 启动**
```powershell
.\start.ps1
```

### 手动启动

**终端 1 - 启动后端：**
```bash
cd server
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

**终端 2 - 启动前端：**
```bash
cd client
npm run dev
```

## 访问地址

| 服务 | 地址 |
|------|------|
| 前端界面 | http://localhost:5173 |
| 后端 API | http://127.0.0.1:8000 |
| API 文档 | http://127.0.0.1:8000/docs |

## 验证服务

运行验证脚本检查服务状态：
```powershell
.\verify.ps1
```

## 环境要求

- **Python**: 3.10+
- **Node.js**: 18+

## 常见问题

### 1. 端口被占用

如果看到端口占用错误，修改端口：
```bash
# 后端
python -m uvicorn main:app --host 127.0.0.1 --port 8001

# 前端（修改 vite.config.ts 中的端口）
```

### 2. 依赖缺失

重新安装依赖：
```bash
# 后端
cd server
pip install -r requirements.txt

# 前端
cd client
npm install
```

### 3. CUDA 不可用

如果没有 NVIDIA GPU，训练将在 CPU 上运行（速度较慢）。

## 停止服务

- **start.bat 启动**：关闭打开的命令行窗口
- **手动启动**：在终端按 `Ctrl+C`

---

**提示**：首次启动会自动安装依赖，可能需要几分钟。
