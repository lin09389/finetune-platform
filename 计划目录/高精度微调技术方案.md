## 1. 技术概述

### 1.1 背景

在模型微调过程中，精度是最重要的指标之一。本方案整合了 7 种主流高精度微调技术，帮助用户在不同资源条件下获得最佳精度。

### 1.2 支持的微调方法

| 方法 | 精度保持 | 显存占用 | 训练速度 | 适用场景 |
|------|----------|----------|----------|----------|
| **全参数微调** | ⭐⭐⭐⭐⭐ 98-100% | 极高 (24GB+) | 慢 | 追求极致精度 |
| **DoRA** | ⭐⭐⭐⭐⭐ 95-98% | 中 (12GB) | 中 | 精度/效率平衡 |
| **高秩 LoRA** | ⭐⭐⭐⭐ 90-95% | 中 (10GB) | 快 | 通用场景 |
| **QLoRA** | ⭐⭐⭐ 85-90% | 低 (6GB) | 最快 | 资源受限 |

### 1.3 核心优化技术

| 技术 | 精度提升 | 实施难度 | 状态 |
|------|----------|----------|------|
| 全参数微调 | +10-15% | 高 | ✅ |
| DoRA (Weight-Decomposed LoRA) | +5-8% | 中 | ✅ |
| 高秩 LoRA | +3-5% | 低 | ✅ |
| 余弦退火学习率 | +2-3% | 低 | ✅ |
| 标签平滑 | +1-2% | 低 | ✅ |
| BF16 混合精度 | +1-2% | 低 | ✅ |
| 早停策略 | +1-2% | 低 | ✅ |

## 3. 实施方案

### 3.1 后端实现

#### 3.1.1 配置模型扩展

**文件**: `server/api/training.py`

```python
class TrainingConfigInput(BaseModel):
    """训练配置输入 - 支持高精度微调"""
    # ... 基础配置 ...
    
    # P2-3: 高精度微调选项
    use_dora: bool = False                    # DoRA 微调
    lr_scheduler: str = "cosine"              # 学习率调度
    warmup_ratio: float = 0.1                 # 预热比例
    weight_decay: float = 0.01                # 权重衰减
    label_smoothing: float = 0.0              # 标签平滑
    gradient_checkpointing: bool = True       # 梯度检查点
    bf16: bool = True                         # BF16 混合精度
    eval_steps: int = 100                     # 评估间隔
    load_best_model: bool = True              # 加载最佳模型
    target_modules: str = "all"               # 目标模块
    lora_dropout: float = 0.05                # LoRA Dropout
    max_grad_norm: float = 1.0                # 梯度裁剪
    
    # 预设配置
    precision_preset: str = "balanced"        # max/balanced/fast
```

#### 3.1.2 精度预设函数

```python
def _apply_precision_preset(config: TrainingConfigInput):
    """应用精度预设配置"""
    
    if cfg.precision_preset == "max":
        # 最高精度配置
        cfg.method = "full" if not cfg.use_dora else "dora"
        cfg.learning_rate = 1e-5
        cfg.lr_scheduler = "cosine"
        cfg.warmup_ratio = 0.1
        cfg.weight_decay = 0.01
        cfg.label_smoothing = 0.1
        cfg.gradient_checkpointing = True
        cfg.bf16 = True
        cfg.eval_steps = 100
        cfg.load_best_model = True
        
    elif cfg.precision_preset == "balanced":
        # 平衡配置
        if cfg.use_dora:
            cfg.rank = 64
            cfg.alpha = 128
        else:
            cfg.rank = 32
            cfg.alpha = 64
        cfg.learning_rate = 2e-5 if cfg.use_dora else 3e-5
        cfg.lr_scheduler = "cosine"
        
    elif cfg.precision_preset == "fast":
        # 快速配置
        cfg.method = "qlora"
        cfg.rank = 16
        cfg.alpha = 32
        cfg.learning_rate = 5e-5
        cfg.lr_scheduler = "linear"
    
    return cfg
```

## 5. 使用指南

### 5.1 快速开始

1. **选择精度预设**
   - 🏆 最高精度 (Max): 全参数/DoRA 微调
   - ⚖️ 平衡精度 (Balanced): 高秩 LoRA
   - ⚡ 快速训练 (Fast): QLoRA

2. **开启 DoRA (可选)**
   - 在 Max 或 Balanced 模式下可开启
   - DoRA 精度接近全参数微调
   - 显存占用与 LoRA 相当

3. **启动训练**
   - 系统自动应用预设配置
   - 实时监控训练进度
   - 自动保存最佳检查点

### 5.2 最佳实践

#### 数据准备
- ✅ 数据清洗：移除低质量样本
- ✅ 数据平衡：确保各类别样本均衡
- ✅ 数据增强：回译、同义词替换

#### 训练监控
- ✅ Train Loss: 应平滑下降
- ✅ Eval Loss: 与 Train Loss 差距<20%
- ✅ Gradient Norm: <1.0

#### 过拟合预防
- ✅ 早停策略
- ✅ 标签平滑
- ✅ 权重衰减
- ✅ Dropout

### 5.3 常见问题

**Q: 显存不足怎么办？**
- 降低 batch_size
- 增加 gradient_accumulation
- 使用 QLoRA 方法
- 减少 max_seq_length

**Q: 精度不理想？**
- 尝试 Max 预设
- 开启 DoRA
- 增加训练数据
- 调整学习率

**Q: 训练速度慢？**
- 使用 Fast 预设
- 开启 BF16
- 减少 eval_steps
