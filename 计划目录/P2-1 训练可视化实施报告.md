#### 1. WebSocket 管理器

**文件**: `server/api/training.py`

```python
class TrainingWebSocketManager:
    """训练 WebSocket 管理器 - 实时推送训练进度"""
    
    async def connect(self, task_id: str, websocket: WebSocket):
        """连接到指定任务的 WebSocket"""
        
    async def disconnect(self, task_id: str, websocket: WebSocket):
        """断开连接"""
        
    async def broadcast_progress(self, task_id: str, progress: Dict):
        """广播训练进度"""
        
    async def broadcast_event(self, task_id: str, event_type: str, data: Dict):
        """广播训练事件"""
```

**特性**:
- ✅ 支持多客户端同时连接同一任务
- ✅ 自动清理断开的连接
- ✅ 心跳检测机制
- ✅ 自动重连支持

## 📊 可视化效果

### 图表展示

| 图表 | 说明 | 颜色 |
|------|------|------|
| Loss 曲线 | 训练损失变化 | #8884d8 (紫色) |
| 学习率 | LR 调度曲线 | #82ca9d (绿色) |
| 显存使用 | VRAM 占用 | #ffc658 (黄色) |

### 实时状态

- **Epoch**: 当前训练轮数
- **Step**: 当前步数 / 总步数
- **Loss**: 实时损失值
- **LR**: 当前学习率
- **VRAM**: 显存使用量 (GB)
- **Elapsed**: 已用时间
- **ETA**: 预计剩余时间

### 连接状态

- 🟢 实时连接中 - WebSocket 已连接
- 🔴 未连接 - WebSocket 断开（自动重连中）

## 🔧 使用指南

### 1. 启动训练

在训练页面选择模型和数据集，点击"开始训练"。

### 2. 查看实时图表

训练开始后，页面会自动显示训练可视化组件：
- 自动连接 WebSocket
- 自动加载历史数据
- 实时更新图表

### 3. Tab 切换

点击不同 Tab 查看不同指标：
- **Loss 曲线**: 观察训练收敛情况
- **学习率**: 查看 LR 调度
- **显存使用**: 监控资源占用

### 4. 断线重连

WebSocket 断开后会自动重连（间隔 3 秒），无需手动操作。
