## 🔧 核心技术详解

### 1. 梯度累积 (Gradient Accumulation)

**原理**: 多次小 batch 累积梯度，模拟大 batch 训练

**配置**:
```python
{
    "batch_size": 1,                # 实际 batch
    "gradient_accumulation": 16,    # 累积步数
    # 等效 batch = 1 * 16 = 16
}
```

**效果**:
- ✅ 显存节省：40-60%
- ✅ 精度无影响
- ⚠️ 训练速度略微降低

---

### 2. 梯度检查点 (Gradient Checkpointing)

**原理**: 不保存所有中间激活，需要时重新计算

**配置**:
```python
{
    "gradient_checkpointing": True,
}
```

**效果**:
- ✅ 显存节省：40-50%
- ✅ 精度无影响
- ⚠️ 训练速度降低 20%

---

### 3. CPU Offload

**原理**: 将优化器状态、梯度等卸载到 CPU 内存

**配置**:
```python
{
    "deepspeed": "zero2",
    "offload_optimizer": True,
}
```

**DeepSpeed ZeRO-2 配置**:
```json
{
  "zero_optimization": {
    "stage": 2,
    "offload_optimizer": {
      "device": "cpu",
      "pin_memory": true
    }
  }
}
```

**效果**:
- ✅ 显存节省：50-70%
- ✅ 精度无影响
- ⚠️ 训练速度降低 30% (受 PCIe 带宽限制)

---

### 4. Flash Attention

**原理**: 优化的 Attention 实现，减少显存访问

**配置**:
```python
{
    "use_flash_attn": True,
}
```

**安装**:
```bash
pip install flash-attn --no-build-isolation
```

**效果**:
- ✅ 显存节省：20-30%
- ✅ 精度无影响
- ✅ 训练速度提升 10-20%

---

### 5. 量化训练 (QLoRA)

**原理**: 4bit/8bit 量化模型权重

**配置**:
```python
{
    "method": "qlora",
    "quantization_bit": 4,          # 4bit 或 8bit
    "bnb_4bit_compute_dtype": "float16",
    "bnb_4bit_use_double_quant": True,
    "bnb_4bit_quant_type": "nf4",
}
```

**SWIFT 命令**:
```bash
swift sft \
  --stage sft-lora \
  --quantization_bit 4 \
  --bnb_4bit_compute_dtype float16 \
  --bnb_4bit_use_double_quant true \
  --bnb_4bit_quant_type nf4
```

**效果**:
- ✅ 显存节省：50-60%
- ⚠️ 精度略微降低 3-5%
- ✅ 训练速度提升 20%

---

### 6. 混合精度训练 (BF16)

**原理**: 使用 BF16 替代 FP32，减少显存占用

**配置**:
```python
{
    "bf16": True,                   # 推荐 BF16
    # 或
    "fp16": True,                   # 或 FP16
}
```

**效果**:
- ✅ 显存节省：40-50%
- ✅ 精度无影响 (BF16 更稳定)
- ✅ 训练速度提升 20-30%

## ⚠️ 注意事项

### 1. 量化精度损失
- 4bit 量化：精度损失 3-5%
- 8bit 量化：精度损失 1-2%
- 建议：优先 8bit，显存不足再用 4bit

### 2. CPU Offload 速度
- 受 PCIe 带宽限制
- 建议：使用 PCIe 3.0 x16 或更高

### 3. Flash Attention 兼容性
- 仅支持 Ampere 架构 (RTX 30 系/A100)
- 建议：检查 GPU 兼容性

### 4. 梯度累积步数
- 过大导致训练不稳定
- 建议：不超过 32 步
