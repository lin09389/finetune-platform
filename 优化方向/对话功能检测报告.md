## 二、对话历史管理 ✅

### 2.1 数据存储

**存储方式**: SQLite 数据库  
**位置**: `server/data/chat_history.db`

#### 数据表结构

**会话表 (chat_sessions)**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PRIMARY KEY | 会话ID (格式: session_YYYYMMDDHHMMSS_xxxx) |
| title | TEXT | 会话标题 |
| model_id | TEXT | 使用的模型ID |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

**消息表 (chat_messages)**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PRIMARY KEY | 消息ID |
| session_id | TEXT | 所属会话ID (外键) |
| role | TEXT | 角色 (user/assistant/system) |
| content | TEXT | 消息内容 |
| timestamp | TIMESTAMP | 时间戳 |

### 2.2 API 端点

| 端点 | 方法 | 功能 |
|------|------|------|
| `/chat/history` | GET | 获取所有会话列表 |
| `/chat/session` | POST | 创建新会话 |
| `/chat/session/{id}` | GET | 获取会话详情+消息 |
| `/chat/session/{id}` | PUT | 更新会话标题 |
| `/chat/session/{id}` | DELETE | 删除会话 |
| `/chat/session/{id}/message` | POST | 批量添加消息 |
| `/chat/session/{id}/message/{mid}` | DELETE | 删除单条消息 |
| `/chat/stats` | GET | 获取统计信息 |

### 2.3 关键逻辑

```python
# 会话ID生成
session_id = f"session_{datetime.now().strftime('%Y%m%d%H%M%S')}_{os.urandom(4).hex()}"

# 消息ID生成

```

**特性**:
- ✅ 支持级联删除 (删除会话时自动删除消息)
- ✅ 自动更新会话时间戳
- ✅ 消息按时间正序排列
- ✅ 统计7天活跃会话数

## 三、对话上下文管理 ✅

### 3.1 核心组件

**文件**: `context/manager.py`

```python
class ContextManager:
    """上下文管理器"""
    
    def __init__(
        self,
        max_tokens: int = 4096,           # 最大Token数
        reserved_tokens: int = 512,       # 保留Token数
        compression_threshold: float = 0.8, # 压缩阈值
        target_utilization: float = 0.6   # 目标利用率
    ):
        self.messages: List[Message] = []
        self.window = ContextWindow(...)
```

### 3.2 消息优先级

| 优先级 | 说明 | 压缩行为 |
|--------|------|----------|
| CRITICAL | 系统消息 | 永不删除 |
| HIGH | 重要消息 | 最后删除 |
| NORMAL | 普通消息 | 正常删除 |
| LOW | 次要消息 | 优先删除 |

### 3.3 压缩策略

| 策略 | 说明 |
|------|------|
| `summary` | 生成摘要替换旧消息 |
| `sliding_window` | 滑动窗口保留首尾 |
| `semantic` | 语义重要性压缩 |
| `importance` | 基于重要性分数压缩 |

### 3.4 API 端点

| 端点 | 方法 | 功能 |
|------|------|------|
| `/dialog-context/message` | POST | 添加消息到上下文 |
| `/dialog-context/system-message` | POST | 设置系统消息 |
| `/dialog-context/compress` | POST | 手动压缩上下文 |
| `/dialog-context/context` | POST | 获取上下文消息列表 |
| `/dialog-context/clear` | POST | 清空上下文 |
| `/dialog-context/max-tokens` | POST | 动态调整窗口大小 |

## 十、潜在问题与建议

### 10.1 发现的问题

| # | 问题 | 严重程度 | 建议 |
|---|------|----------|------|
| 1 | 对话历史无分页 | 低 | 大量会话时可能影响性能 |
| 2 | 上下文压缩可能丢失重要信息 | 中 | 建议添加用户确认选项 |
| 3 | Agent执行无回滚机制 | 中 | 建议添加操作日志和撤销功能 |

### 10.2 优化建议

1. **性能优化**
   - 添加会话列表分页
   - 消息懒加载
   - 压缩策略可配置化

2. **用户体验**
   - 添加消息编辑功能
   - 支持消息重新生成
   - 添加对话导出功能

3. **安全增强**
   - Agent操作审计日志
   - 敏感操作二次确认
   - 操作撤销功能
