```
✅ 要做：
- 加密存储
- 只存哈希值
- 不上传到云端
- 定期更换

❌ 不要：
- 明文存储
- 上传到 GitHub
- 分享给他人
- 写在客户端代码里
```

```
✅ 建议：
- 设置每日预算
- 监控用量
- 设置用量告警
- 选择便宜的模型

❌ 避免：
- 无限制调用
- 不监控用量
- 用最强模型做简单任务

```
